## 2. 情報源の優先順位

矛盾がある場合は次を優先する。

1. ポータルの正誤表・変更通知
2. 対象入学年度の学修要覧・履修要綱
3. 対象年度の授業時間表・訂正表
4. 対象年度の公式プログラム募集要項・ハンドブック
5. 大学・学部・学科の公式Webページ
6. 過年度の公式資料

`docs/source-manifest-2026.json` の次の属性を必ず使用する。

- `authority`
- `freshness`
- `autoDecisionAllowed`
- `notes`

`autoDecisionAllowed=false`の資料だけでは、卒業、進級、修了を達成済みにしない。

公式PDFはGitへ格納しない。次でローカルキャッシュへ取得する。

```bash
npm run sources:fetch
```

保存先:

```text
.cache/official-sources/2026/
```

取得レポートにはURL、取得日時、サイズ、SHA-256を残す。

## 5. 電気電子通信工学科 2026年度確定ルール

sourceId: `tcu-2026-denki-handbook`

### 履修指導

- 各セメスターの履修登録上限: 24単位
- 1年次前期取得10単位未満: 指導警告
- 1年次終了時取得20単位未満: 指導警告
- f-GPA 0.6未満: 退学勧告対象の警告
- f-GPA 1.5未満: 面談対象の警告

卒業判定ではなく、リスク・指導表示として扱う。

### 3年次進級

- 卒業要件非加算科目を除き、2年次終了時に60単位以上

### 4年次進級

- 3年以上在学
- 卒業要件非加算科目を除き、合計100単位以上
- 共通分野15単位以上
  - 教養8
  - 体育1。選択必修1を1含む
  - 外国語6。必修3を含む
- 専門分野76単位以上
  - 理工学基礎28
    - 必修13
    - △1を4以上
    - △2を2以上
  - 専門48
    - 必修22
    - △1を10以上
    - △2を2以上

総単位100だけで達成扱いにしない。

### 卒業研究

- 卒業研究(1): 原則4年次進級条件を満たす
- 一貫教育等の早期着手: 学科承認が必要
- 卒業研究(2): 卒業研究(1)を修得済み

学科承認は人間確認フラグなしで自動合格にしない。

### 卒業

- 合計124単位以上
- 共通分野19単位以上
  - 教養10
  - 体育1
  - 外国語8。必修4を含む
- 専門分野91単位以上
  - 理工学基礎31
    - 必修17
    - △1を4以上
    - △2を2以上
  - 専門60
    - 必修32
    - △1を10以上
    - △2を2以上
- DS・MS指定科目を合計4単位以上
- DS指定科目を1単位以上
- MS指定4単位は理工学基礎必修に含まれる
- DS指定1単位は別判定が必要
- 理工学基礎31単位超過分は、認められる範囲で自由選択へ回す

`elective-required`だけでは不足する。△1と△2を別フィールドで集計する。

### TAP参加者

- TAP参加者も所属学科の進級・卒業条件は同じ
- 留学中に履修できない科目は開講時期により1年遅れる可能性がある

TAP参加を理由に学科要件を緩和しない。

## 8. 実装モデル

全ルール・科目対応・訂正に出典を持たせる。

```ts
type SourceMetadata = {
  sourceId: string;
  sourceUrl: string;
  sourceTitle: string;
  sourceYear?: number;
  sourcePage?: number;
  checkedAt: string;
  contentSha256?: string;
  confidence: 'confirmed' | 'provisional' | 'historical';
  reviewStatus: 'verified' | 'needs_human_review';
};
```

履修ルールは次を表現できる構造にする。

- 総単位
- 区分別単位
- 必修
- △1
- △2
- DS/MSタグ単位
- 特定科目修得
- 在学年数
- GPA
- 語学スコア
- 出席率
- 学科承認

時間割訂正は`before`、`after`、`source`を持つ差分データにする。

特別プログラムは所属学科ルールを上書きせず、年度・学部・学科付きオーバーレイにする。

## 10. 必須テスト

### 履修実績

- 同一科目を複数Qへ登録しても一度だけ数える
- 不可と再履修合格がある場合は合格を採用
- 未履修と合格がある場合は合格を採用
- M1/M2科目を学部卒業単位へ加算しない
- 区分不明科目を自動算入しない

### 区分判定

- 1科目を複数区分へ算入しない
- 必修、△1、△2を別々に検査
- 区分超過分だけ自由選択へ回す
- 自由選択と他区分を二重計上しない
- DS/MSタグを別判定

### 進級・卒業研究

- 59単位は3年次進級不足、60単位で総単位条件達成
- 99単位は4年次進級不足
- 100単位でも区分不足なら未達
- 在学年数不明なら自動達成にしない
- 卒業研究(1)未取得なら卒業研究(2)着手不可
- 早期着手は承認フラグが必要

### 時間割

- 3Q、4Q、後期、後集中、通年を区別
- 同一講義コードの複数クラスを保持
- 訂正前後を追跡
- 前期データだけでも既存画面が壊れない
- 後期追加後に年間検索可能

### 特別プログラム

- TAP参加でも所属学科要件を緩和しない
- ATAP条件不足を不足または要確認にする
- TUCP過年度資料だけで2026年度修了判定しない
- 国際イノベーターの2026年度と過年度条件を混ぜない
- ひらめき認定先未確認科目を自動算入しない
