# 学生向けUI/UX再設計（2026-09-07）

## 問題と変更

ホームの装飾カレンダーは実際の登録を表していなかった。曜日別の登録コマ数を棒グラフに変更し、予定一覧も曜日・時限順に並べた。5コマを超える場合は省略件数と時間割への導線を明示する。空の時間割へのボタンは、遷移先と一致する「時間割をつくる」に修正。

成績は一覧を探し続ける必要があった。検索と成績フィルタを追加し、未入力の科目へ絞れるようにした。表示学年の成績内訳を科目数のドーナツで表示する。グラフは検索前の学年全体を示し、取得単位・累計GPAとは分母を分ける。既存の重複科目集約を使用し、予定を合格として扱わない。

主色・認証ボタン・管理画面の選択色・履修ガイド・教員教場入力をブルー系に統一。DESIGN.mdに根拠、配色値、グラフの分母、モバイル規約を記録した。外部チャート依存は追加していない。

- ホーム：予定の順序、未登録の導線、一覧省略の説明を修正。

- 履修ガイド：元資料ハッシュ・重複単位・再履修・不合格の既存テストを通過。原本分類の未確認事項は今回解消したと扱わない。
- 認証・初期設定・管理・問い合わせ・保存：既存のGoogle認証とSupabase RLS/RPCの検証を再実行。別ユーザー隔離、権限注入拒否、保存競合、問い合わせ回答、プログラム8通りを通過。
- PythonのDB・アカウント・管理・開講情報テスト26件通過（学科・年度95通りのAPI確認を含む）。
- TypeScript、変更3コンポーネントのESLint、公開verify/build通過。公開ビルドには約561kBのJSチャンク警告が残る。
- Playwrightの検証用画面でデスクトップと390px幅を撮影・確認。横はみ出しなし、未入力フィルタで英語1科目になることを確認。検証用画面のfavicon未配置による404のみ記録。
