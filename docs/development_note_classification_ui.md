## 原本との照合

119件の学修要覧のSHA-256を照合し、座標確認済み科目行を原本の結合セルへ対応付けた。分類証拠には原本ハッシュ、ページ、セル座標、区分階層を保存。縦書きは列順も確認し、既知ラベルと一致しない文字列は未解決として残す。科目名の部分一致で区分を推定しない。

95通りのうち科目データがあるのは94通り。そのうち63通りでは表示対象の全科目に分類証拠がある。残る区分未確認は表示対象で延べ1,200行、元資料の科目行では878行（文字・結合セルの確認747行、分類セル取得不可131行）。共通資料を複数学科で使用するため両者は異なる。119件の全ページを人が目視確認したという意味ではない。

目視例：2025環境学部PDF83ページは「目」がテキスト抽出に現れず、原本画像では「基礎科目／外国語科目／英語科目（スキル・教養）」を確認できる。この種の欠落を推測補完で確定扱いにしていない。残るページにも原本に結び付いた修正証拠が必要。

## 修正した問題

1. 大区分と科目群の混在：原本の左側の結合セルから階層を保持。ハッシュ不一致、分類未確認は「区分未確認」に分離。
2. 共通資料が学科固有の分類を上書き：学科固有の証拠を優先。別学科の必要単位を採用しない。
3. 旧成績構造の参照：区分詳細を実際の学年・Q・曜日・時限の時間割セルから集計。未登録と予定、不合格を分け、再履修合格や重複コマを二重加算しない。
4. 検索後の件数と単位合計の対象不一致：一覧は表示対象に統一し、区分全体の進捗との違いを明示。
5. TAP資料ハッシュ不一致：既存検証による取込停止を維持し、公式ページを再取得して証拠を更新。検証条件を緩めて通していない。加えてGitの改行変換警告を検出し、原本HTMLを `.gitattributes` で `-text` に指定した。今後のcheckoutでハッシュ対象バイトが変わることを防ぐ（今回の不一致原因が改行だけだったとは断定しない）。

UIはDESIGN.mdの色・余白・44px操作領域を継承し、区分カード、科目群、検索・状態フィルタ、条件の開閉を整理した。
